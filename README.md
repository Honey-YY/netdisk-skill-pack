# 资料蒸馏 Skill 包

把你在百度网盘里买的课程、电子书，蒸馏成自己能一句话调用的 AI 技能。

## 这个包解决什么问题

买了很多课，收藏夹落灰，想用的时候找不到、也懒得翻。

这个包让 AI 帮你把资料读一遍，提炼成技能。**装完之后，像聊天一样说话就能用。**

## 里面有什么

| 技能 | 作用 |
|---|---|
| `网盘资料采集` | 后台帮你把资料从网盘抓完整，避免漏文件。你不用管它 |
| `现代思维工具` | 一个真实案例：把一门100 讲的课蒸馏成能用的技能。照着改就能换成你自己的资料 |

## 怎么安装

### 最省事：让 AI 帮你装（推荐）

把这句话发给 AI，它会自动下载并安装：

```
从这个地址下载并安装成 skill：https://github.com/Honey-YY/netdisk-skill-pack/releases/download/v1.0.0/netdisk-skill-pack.zip
```

### 手动下载

**[点此下载 netdisk-skill-pack.zip](https://github.com/Honey-YY/netdisk-skill-pack/releases/download/v1.0.0/netdisk-skill-pack.zip)**（70 KB）

解压后把 `skills` 文件夹里的两个文件夹复制到：

- **Windows**：`C:\Users\你的用户名\.workbuddy\skills\`
- **Mac / Linux**：`~/.workbuddy/skills/`

### 用 git clone

```bash
git clone https://github.com/Honey-YY/netdisk-skill-pack.git
# 然后把 skills/ 下的文件夹复制到你的 .workbuddy/skills/
```

装完长这样：

```
~/.workbuddy/skills/
├── 网盘资料采集/
│   └── SKILL.md
└── 现代思维工具/
    ├── SKILL.md
    └── references/
        ├── 方法论索引.md
        ├── 方法论-目标与选择.md
        ├── 方法论-认知与学习.md
        ├── 方法论-组织与制度.md
        ├── 方法论-行动与决策.md
        ├── 方法论-创造与增长.md
        └── 方法论-全量.md
```

### 验证装好没有

新开一个对话，说一句：

```
我不知道该干什么
```

如果它没有直接甩给你一堆建议，而是先问你问题、然后给 3 条今天就能做的动作 —— 说明装成功了。

## 怎么用

### 1. 连上百度网盘

WorkBuddy 左侧菜单 → **专家·技能·连接器** → 找到「百度网盘」→ 点 **连接** → 扫码。

### 2. 说一句话

```
用百度网盘连接器，把 /我的资源/你的资料目录 下的资料蒸馏成 skill
```

就这一句，AI 会自动把资料读完整、提炼成卡片、装好、告诉你怎么用。

**不知道资料在哪？** 先说一句：

```
用百度网盘连接器，列出根目录所有文件夹
```

### 3. 以后就这么用

新开一个对话，像平时说话一样：

```
我不知道该干什么
帮我拆解一下这个问题
学不进去怎么办
```

不用记技能名，不用打斜杠命令。

## 换成你自己的资料

`现代思维工具` 是从一门 100 讲的课蒸馏出来的。换成你自己的资料，照这个结构改：

```
你的技能名/
├── SKILL.md← 必填
└── references/
    ├── 方法论索引.md      ← 相当于目录
    ├── 方法论-xxx.md       ← 一个主题一个文件
    └── 方法论-全量.md      ← 备份，一般用不到
```

**为什么要拆成多个文件？**

AI 每次只看你指定的那一个文件。全塞进一个大文件，AI 会被无关信息干扰，回答质量下降。

**一个必须注意的细节**

文件夹名必须和 `SKILL.md` 里 `name:` 后面的字**完全一致，一个字都不能差**。名字里可以有中文。

## 常见问题

**Q：AI 说找不到我的文件？**

路径要写完整路径（`/我的资源/100讲`），不能只写名字。中文不用自己转码，直接写。

**Q：抓出来的资料比实际少？**

补一句：`继续翻页，直到返回空为止`

**Q：能处理视频课吗？**

能，但效果打折。视频得先转文字，误差比文字版大。建议优先处理音频和 PDF。

**Q：Token 过期了？**

有效期约 30 天。到期后在连接器管理里重新连一下、扫个码就行。
