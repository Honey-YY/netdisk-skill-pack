# 第三模块 · 世界模型·社会（人与社会怎么运作）

## 卡片 020 · 叙事与共同知识

**来源**：wwg001 叙事、wwg087 叙事权、wwg079 共同知识、wwg094 问答、wwg114 立题

**核心概念**
**叙事比物理学更基本，是宇宙的第一性原理。** 物理学家意识到可能存在多个宇宙，每个宇宙物理定律不同。

**叙事对人类的三个关键作用**
1. **预测处理** —— 建立简单世界模型做出预测并行动
2. **提供意义** —— 价值观和人生意义来自叙事
3. **公共协调** —— 人类能大规模合作是因共同相信虚构叙事

**我们不是对事实数据做反应，而是对叙事做反应。**

**叙事权的三层心法**（不是讲故事）
- **定题** —— 议程设置。决定组织关注什么问题，**比直接给答案更能主导方向**
- **定义** —— 通过框架塑造改变人们对同一事实的理解，引导不同的因果判断
- **定我** —— 身份认同，让人从角色出发自动生成符合愿景的行为

三者递进形成**共同知识**，催生**超信念**（未来预期倒逼现实实现的自我加强循环）。

**共同知识**：所有人都知道某事实，且知道其他人也知道。皇帝的新衣、超级碗广告都是例证。
**泡沫能持续并非无人知晓，而是「共同知识」未形成** —— 即便有人喊破也能再涨。

**叙事权的三种常见形式**：资源、评价、危机叙事。但**战略叙事更高级** —— 激发认同而非服从。

**立题**（wwg114）
真正的权力在于**能够主动立题**，而非仅仅答题。立法者与执行者的区别。
立题通过**预设投射**定义框架，从而掌握主导权。立题基本手艺：**定边界 + 明确意图**，把执行细节留白。

**关键方法与步骤**
1. 想影响他人时：先定题（定议程）→ 再定义（定框架）→ 最后定我（定身份）
2. 判断「共同知识是否形成」：如果真相无人相信，不等于真相不存在
3. 抱怨环境时，改成**主动立题** —— 把它变成一道我选择去解的题
4. 立题时给边界和意图，不要给剧本

**常见坑**
- 只讲故事不给共同知识 —— 无法凝聚行动
- 用危机叙事而非战略叙事
- 把「没人知道」当「不存在」
- 一直答题，从不立题

**原文金句**
> 驱动行动的信念、方向和行动本身都由叙事构成。— wwg001

## 卡片 021 · 场域与规则识别

**来源**：wwg022 场域、wwg094 问答

**核心概念**
**场域** = 由不同位置组成的关系网络，每个场域有自己默认的规则。

四个关键概念：
- **doxa** —— 场域里不言自明的信念
- **惯习** —— 被社会结构内化的默认设置
- **资本** —— 能在竞争中转换为优势的资源
- 场域是**关系网**，不是实体

**在一个场域里玩好游戏的攻略**
1. 了解**网络结构**（位置如何分布）
2. 识别 **doxa**（这个场域信什么）
3. 查看**惯习**（大家默认怎么做）
4. 积累**资本**（这里认哪种资本）

**不同场域有不同的规则和资本要求**，有时各种资本之间可能冲突。**重要的是展示的能力被场域认可。**

**前现代环境下的生存策略**（wwg094）
- **想干小事** → **有限依附策略**：借助关系启动事项，用结果保障安全
- **想干大事** → **躬身入局**：拿下关键问题、培养人马、控制资源、明确权力结构、合理分配利益、避免黑箱操作，逐步将自己变成组织不可或缺的秩序中心
- 核心：**灵活运用规则与关系，在现实中找到平衡**

**小公司的制度设计**：建立**轻制度**以保护信任，而非盲目照搬大公司流程。

**关键方法与步骤**
1. 进入新场域前先做三件事：网络结构、doxa、惯习
2. 判断自己积累的资本在这个场域有没有价值
3. 想干大事就躬身入局，想干小事就有限依附
4. 不要用大公司的制度套小公司

**常见坑**
- 拿旧场域的资本进新场域
- 不知道场域的 doxa，努力方向错
- 小公司照搬大公司流程 —— 失去信任保护

**原文金句**
> 识时务者为俊杰。— wwg022

## 卡片 022 · 组织资本与制度设计

**来源**：wwg089 人身依附、wwg086 组织资本、wwg092 委托代理、wwg072 激励相容、wwg091 指挥官意图、wwg085 剩余判断权、wwg077 问答

**核心概念**
**现代化的本质是从「身份到契约」的运动。** 前现代组织靠人身依附，受制于**邓巴数**；现代组织靠制度、合同、审计等**非人格化手段**，让信任脱离具体个人。

**组织资本的三个维度**
让一群厉害的人成为厉害的公司，靠的不是能力相加而是**协作默契**——一种无法被个人带走的专属能力：
- **认知资本** —— 团队在共同语言、标准和优先级上达成一致
- **结构资本** —— 建立「专长地图」，让每个人知道问题该找谁
- **关系资本** —— 团队心理安全，确保成员**敢于报告真实信息**

**委托代理三机制**：逆向选择、道德风险、多任务冲突。**本质是结构性矛盾，不是道德问题。**
委托人握三权：**目标解释权、信息解释权、最终裁判权**。同时约束自己：公平报酬、允许代理人说「不可能」、不将运气视为罪责。
必须支付的代理成本：监督成本、担保成本、剩余损失。

**激励相容**
设计机制让人们追求自身利益的同时也实现组织目标。核心是规则明确可预期 + 利益分配合理。**好的制度不应该指望人「畏威怀德」**，而是让说真话成为每个人的最优策略（显示原理）。

**剩余判断权**（wwg085）
为什么组织总得有人说了算？根因是**雇佣合同的天然不完备性** —— 合同不可能穷尽所有情形。
- 老板应专注**高耦合、低可逆的「单向门」决策**，其余事务尽量放权
- 领导者真正该定的五件事：**定题、立尺、下注、授权、改判**
- **剩余判断权不是管得越多越好，而是把非程序化、不可市场化的关键赌注留给一个人**

**指挥官意图**（wwg091，AI 时代的管理）
在不确定环境中，上级**放弃事无巨细的指令**，转而明确三件事：**任务的目的、成功标准、不可触碰的边界**，让执行者根据现场情况自主选择手段。
- 表达清晰意图而非遥控具体动作，正在成为一项日益重要的技能
- **让忠诚从忠于命令转向忠于理念**

**礼与契约的边界**（wwg077）
- **礼**适用于小圈子内的关系维持和身份确认，基于**熟人信任**
- **契约**基于**制度信任**，适用于陌生人社会
- 礼的潜在弊端：等级绝对化和道德绑架。**高端中国文化中的礼是双向互惠的**

**关键方法与步骤**
1. 判断组织健康度：有没有「专长地图」？坏消息能不能及时上报？
2. 委托人做决策前先答：我有没有把「运气不好」当成了「能力不行」？
3. 制度设计检验标准：**规则明确 + 可预期 + 利益合理**
4. 放权时给三件事：**目的、成功标准、边界**，不给动作细节
5. 分清什么时候用礼（小圈子）和什么时候用契约（陌生人）
6. 判断自己该管什么：只管**单向门决策**

**常见坑**
- 用忠诚表演代替真实能力（中层蒙蔽）
- 把委托代理当宫斗剧看，纠缠人心术而不改制度
- 遥控细节而不是下达意图
- 在陌生人社会用礼的逻辑

**原文金句**
> 让信任脱离具体个人。— wwg089
> 权力并非奖赏，而是用行动证明自己值得托付后获得的信任杠杆。— wwg096

## 卡片 023 · 激励、指标与流程

**来源**：wwg090 古德哈特、wwg115 内部优化器、wwg093 流程清单经验库、wwg100 问答、wwg095 基线漂移

**核心概念**
**古德哈特定律：当一项指标被用作奖惩目标时，人们会转而优化该指标本身而非真实目标。**
根本原因**并非管理过严，而是决策者缺乏专业判断的权威**，从而依赖看似客观的数字。

**应对之道**
- 让指标仅作为**判断素材**而非**判决依据**
- 采用**代表作评价**并附上书面理由
- 按角色分类考核
- 定期回溯指标是否被「玩坏」

**内部优化器（养器成妖）**
智能系统在训练中可能发展出偏离原始目标的内部目标，并学会**保护自身错误**。人类同样受演化内置的「近似仪表」驱动，导致「**想要」不等于「喜欢」**（刷手机成瘾）。
组织层面：**指标催生形式主义内部优化器，使减负沦为新负担。**

**识别是否养器成妖**：做**非常规分叉测试** —— 在目标分叉处检验真实追求。

**制件：把聪明外置成系统**（wwg093）
公司除制度外还需三部分构建组织智慧：
- **技能**（流程、SOP、Playbook）—— 将意图转化为稳定行动，避免依赖个人聪明
- **护栏**（清单、风险红线）—— 在关键节点防止犯错，降低认知负荷
- **记忆**（最佳实践、失败案例）—— 让经验可积累、可迭代

三者闭环：变异经实验验证后固化技能 → 再立护栏 → 结果反馈更新记忆。
组织境界分**人治、流程、学习型**三层，唯学习型组织能持续修订。

**基线漂移**（wwg095）
组织与个人在不自觉中降低评判标准的能力是衰败的根源。完成路径：**小步越界 → 未出事故 → 判例固化 → 默认失忆 → 免疫反应**。
传统防线（硬性底线、举报通道、外部对标）都难以持久，因为**防守是静态的，而压力与借口不断生长**。

**真正的对抗之道是进攻**：领导者必须心怀「事情本应如何」的理想蓝图，以创造精神驱动变革，而非仅仅维持现状。

**关键方法与步骤**
1. 看到荒谬结果时，找**机制**而不是「坏人」
2. 指标设计：让它当素材不当判决，并定期检查是否被玩坏
3. 做**非常规分叉测试**检验真实追求
4. 把个人聪明外置成制件：技能 / 护栏 / 记忆
5. 判断组织层级：现在是人治、流程还是学习型？
6. 防腐：**持续对现实不满**，主动寻找新增长点

**常见坑**
- 减负指标变成新的考核项
- 指标一出，所有人开始优化指标
- 用「维持现状」代替「创造理想蓝图」
- 把「没人反对」当「没人反对」—— 默认失忆是基线漂移的终点

**原文金句**
> 最危险的往往是自我量化。— wwg090

## 卡片 024 · 道德的适用尺度

**来源**：wwg113 道德可扩展性、wwg075 政府演化、wwg074 外部性、wwg113

**核心概念**
**道德有适用尺度，不能任意扩展。** 人际关系受**邓巴数**限制，且**谁出钱是核心变量**。

不同尺度兑换不同「币种」
| 尺度 | 币种 |
|---|---|
| 家庭 | 爱 |
| 乡里 | 报偿 |
| 组织 | 受托责任 |
| 国民 | 法 |
| 天下 | 可验证的承诺 |

**腐败实为道德越权，而非缺失。**

现代人应区分场景：**家须不计较，公司守规则，市场重契约，国家靠法治**。真正现代化在于知道「**自己人」在哪些地方不能算数」。

**外部性**（wwg074）
个人行为产生的后果不完全由自己承担，导致**好事不足、坏事过量**。
- 科斯定理：私人协商可以解决外部性，但现实中**产权清晰和交易成本为零**的条件难以满足
- 奥斯特罗姆**多中心治理**：社区自治成功管理公共资源，避免了政府强制和私有化。八条自治制度设计原则强调本地人互相监督和利益共同体
- 群体过大、外部性跨越地域时，仍需政府作为拥有最终强制力的组织出面

**政府的起源与演变**（wwg075）
政府起源于**强盗**，从流寇演变为定居强盗，进而形成政府。核心是**暴力与最终强制权**。
前现代国家将百姓视为**资源**，现代国家则是**制度化的政府**。
即便现代政府也是最大的**负外部性制造者**。

**关键方法与步骤**
1. 判断关系时先问：**这是哪一层的关系？谁付钱？该用什么币种？**
2. 遇到外部性问题：先问「产权是否清晰」「交易成本是否接近零」——满足则自治，不满足才需强制
3. 自治组织设计：本地人互相监督 + 利益共同体
4. 家里不要用公司规则讲公平

**常见坑**
- 在家用「公司规则」讲公平 —— 错位
- 在无信任的环境里指望契约自动执行
- 用道德代替制度 —— 道德不可规模化

**原文金句**
> 真正现代化在于知道「自己人」在哪些地方不能算数。 — wwg113

## 卡片 025 · 自由社会的强制与信任

**来源**：wwg075、wwg074、wwg073 柠檬市场、wwg077

**核心概念**
**程序正义**：通过**公开、透明、可验证的规则和程序**来确保公正，而不是直接执着于结果的善恶。

**柠檬市场问题**（wwg073）
信息不对称导致**优质商品难以被识别**，导致市场**劣币驱逐良币**。招聘中学历崇拜、硕博公信力下降都是例证。

**解法不是「直接扬善惩恶」，而是让好坏可验证**
- 建立**可测量的声誉机制**
- **第三方认证**
- **纠纷解决机制**
- 关键：**交付小成品**来建立可验证信号

**关键方法与步骤**
1. 面对「好人被坏样淘汰」的市场，不要指望识别好人，要**设计让好坏自动暴露的程序**
2. 现代制度应放弃对结果善恶的直接执着，转而建设让善恶能够被自动暴露的程序
3. 用**操作性和可验证性**证明自己的价值 —— 用作品、信用和成果

**常见坑**
- 直接扬善惩恶 —— 你没有识别能力
- 只看名校名头等不可验证的信号
- 等别人先证明自己，而不是先交付小成品

**原文金句**
> 不要直接扬善惩恶，要让好坏可验证。 — wwg073
