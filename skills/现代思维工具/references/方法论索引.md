## 五、三条贯穿主线

### 主线 1：找坏人 → 看系统 → 改条件
涉及卡片：022, 023, 025, 031, 041

遇到问题时：
1. 不要问「谁做错了」→ 问「什么样的系统条件会让所有人做错」
2. 不要问「谁是坏人」→ 问「基本归因谬误在这里扮演什么角色」
3. 不要问「怎么改人」→ 问「怎么改激励和条件」

### 主线 2：效果推理 ↔ 因果推理切换
涉及卡片：030, 002

- **迷茫、不知道该干什么时** → 效果推理（先动起来，用已有资源改变结果）
- **目标清晰、不知道怎么干时** → 因果推理（优化路径）
- 判断口诀：不知道干什么 = 效果；知道干什么不知怎么干 = 因果；都不确定 = 先效果后因果

### 主线 3：寻找能做庄家的位置
涉及卡片：032, 033, 041

- 找**经济租**：占住不可替代的位置
- 找**结构洞**：翻译、连接不同领域
- 找**不均衡**：市场错配处就是机会
- 找**第一性原理**：剥到最基本再重建
- 找**冷门赛道 + 多面手**：避开单一指标的锦标赛

## 六、覆盖边界

**这套工具不覆盖**：具体编程实现、法律条文、医疗诊断、财务计算、翻译。这些直接用通用方式回答，不要硬套模型。

**只覆盖通用层**：怎么想问题、怎么拆解、怎么判断、怎么行动。领域知识本身需要另行提供。
